# Space 1.6.0 界面与任务说明迭代

日期：2026-11-01；作者：吴炎；目标：1.6.0 build10。

基于用户提供的八张截图和当前1.5.0原生源码分析。本轮直接在现有SwiftUI应用迭代。

## 修改任务与验收

| 编号 | 修改任务 | 验收标准 |
|---|---|---|
| 001 | 精简导航 | 侧栏仅保留“任务”和设置；移除今天、逾期、已完成、工作、个人、生活入口；首页名称改为任务。分类与完成状态数据保留供筛选使用。 |
| 002 | 筛选浮层 | 每个条件上方显示label，下方显示控件；条件区可纵向滚动，标题、匹配数量、清除操作固定。 |
| 003 | 顶部分类快筛 | 点击工作/个人/生活切换分类条件，再次点击取消；与其他筛选叠加；选中状态可见；计数展示完整任务库分类数量，避免筛选后其他分类全部变零。 |
| 004 | 设置弹窗 | 上下区域均48pt，左右均24pt内边距；标题与关闭按钮垂直居中，完成按钮32pt。 |
| 005 | 任务弹窗 | 新建与详情复用相同48pt标题/底栏、32pt底栏按钮；正文独立滚动。 |
| 006 | 图文说明 | 富文本支持加粗、下划线、光标位置粘贴图片；保存、重开后保留图文；文本仍可搜索；附件错误反馈可见；取消不提交。 |
| 007 | 月历溢出 | 任务预览和“还有N项”均留在日期格内；还有按钮选中当日并在右侧显示完整清单。 |
| 008 | 查看日期 | 甘特图与日历使用日历选择器；初始今天，支持指定日期；甘特图只显示所选日到第14天（含所选日，共14天），移除周数选择。 |

## 影响确认

导航页面入口合并；任务查询沿用原有条件。保留SwiftUI/AppKit原生实现和既有苹方、毛玻璃风格。
富文本采用可选RTFD字段，普通说明作为搜索及卡片摘要；原附件保留，内嵌图片也存在RTFD中。JSON含富文本时使用V6，SQLite含富文本时升级至版本3，防止旧应用保存时丢失格式。升级只发生在保存富文本之后；兼容读取已有JSON V1至V5、SQLite版本1/2。同步与撤销通过完整任务负载保留新字段。
