# Space · 个人本地工作台

**安排好每一步，留一点空间给生活。**

Space 是一款面向个人的桌面工作台，将工作任务、个人计划和生活待办集中在一个空间里。用看板梳理进度，用列表整理细节，用甘特图规划项目，用日历安排每一天，让零散的事情变成清晰、可推进的计划。

数据保存在本机，日常使用无需联网；需要在不同电脑之间接续计划时，可以通过云端数据同步，将自己的工作台带到另一台设备。

支持 **macOS Apple Silicon** 与 **Windows 11 x64**。

[下载 Space](downloads/) · [macOS 使用说明](flutter/INSTALL-macOS.md) · [Windows 使用说明](flutter/INSTALL-Windows.md)

## 从自己的喜好出发

Space 是一个普通人在 AI 的帮助下，把个人喜好和日常需求变成软件的尝试。从界面风格到使用方式，都源于一个朴素的想法：做一个自己喜欢、用得顺手的工作台。在 AI 时代，普通人也有机会把心里的“我想要”，一步步做成生活里的“我在用”。

## 把工作与生活，放进自己的节奏

工作项目、学习计划、旅行准备，或是一件随手记下的小事，都可以从一项任务开始。Space 提供工作、个人、生活分类，也支持添加和编辑自己的分类，让不同角色下的安排各有归属，也能随时回到同一个工作台查看全貌。

为任务设置优先级、所属项目、开始日期和截止日期，把想法变成下一步行动。通过概览了解整体进度，再用搜索、多选筛选和排序聚焦眼下的事情；常用条件可保存为默认配置，下次打开继续使用。

## 一份计划，四种查看方式

同一组任务可以随时切换视图，按照当前需要组织信息。

| 视图 | 适合怎样使用 |
| --- | --- |
| **看板** | 按状态查看任务，拖动卡片推进进度；每列宽度可独立调整，让常用内容更舒展。 |
| **列表** | 集中查看任务信息，快速浏览、筛选和整理，适合逐项处理日常待办。 |
| **甘特图** | 按项目查看当前月时间安排，切换日、周、月刻度，左右滚动查看相邻月份，拖动任务条调整日期和时长。 |
| **日历** | 在日、周、月之间切换；月视图随格子高度展示任务，剩余数量清晰提示，也可以直接为当天新建任务。 |

## 让任务承载完整的上下文

任务里既能记录要做什么，也能放下完成它所需的资料。

- **图文说明**：用富文本整理思路，插入图片，让需求、笔记和参考内容更直观。
- **文件附件**：把相关资料随任务保存，支持预览、另存和移除，减少来回查找。
- **项目归档**：将同一目标下的任务归入项目，统一查看和安排；项目支持改名、停用和重新启用。
- **自定义状态**：按自己的工作方式创建和排列状态，让流程贴合实际习惯。
- **完成与撤销**：完成后清楚标记，需要继续时重新打开；误操作后可撤销最近一次更改。

## 本地使用，云端接续

Space 以本地工作台为中心，任务和设置保存在自己的电脑上，离线也能继续记录、整理和推进计划。

需要云端备份或换一台电脑继续使用时，可在设置中连接自己的 **GitHub 私有仓库**，填写访问令牌并设置恢复密钥：

- **同步数据到云端**：手动上传当前完整任务数据，更新云端备份。
- **恢复云端数据**：在另一台设备上连接同一仓库，使用相同恢复密钥，取回任务、项目和状态。
- **加密保存**：任务数据加密后上传，恢复时使用自己设置的密钥。

同步时机由自己决定。切换设备时，在原设备上传，再到另一台设备恢复，即可接续安排。恢复云端数据前，Space 会先备份本地任务库。

## 为自己的计划留一份备份

除了云端同步，Space 也支持在设置中导出和导入本地备份，方便定期留存、迁移电脑或恢复已有安排，并提供恢复上次备份的入口。

本地备份采用 SQLite 文件，可连同任务、项目、状态和相关设置一起保存。备份中包含本机连接配置，请妥善保管；使用云端恢复时，也请保留好恢复密钥。

## 一个适合每天打开的桌面空间

浅色、深色与跟随系统三种外观，配合毛玻璃、柔光和卡片流光，让工作台有清晰的层次，也保留一点轻松感。

侧栏与概览可分别收起，为任务内容腾出空间；看板列宽会记住自己的调整，滚动条也可在设置中统一隐藏。常用操作支持键盘快捷键，让记录、查找和整理更顺手。设置按全部设置、外观与交互、备份与恢复、云端同步、数据管理和关于 Space 分栏排列。跟随系统时，主界面的明暗切换只在当前会话临时生效，系统外观变化后恢复跟随；在设置中选择浅色或深色则固定使用。关于页会检查新版本，并提供手动下载入口。

## 从第一件小事开始

1. 下载适合自己电脑的版本，打开 Space。
2. 新建一项任务，写下现在想完成的事情。
3. 按需补充分类、优先级、项目和日期，选择顺手的视图开始推进。
4. 在设置中选择外观，导出一份本地备份，或连接云端同步。

macOS 可选择 DMG 或 ZIP；Windows 使用免安装 ZIP，完整解压后打开 `Space.exe`。
