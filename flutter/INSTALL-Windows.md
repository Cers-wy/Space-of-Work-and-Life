# Space 2.3.3 · Windows 11 x64

可选择 EXE 安装包或免安装 ZIP。

## EXE 安装

运行 `Space-2.3.3-Windows-x64-Setup.exe`。在目录选择页点击 Browse 选择安装路径，再继续安装。默认仅为当前用户安装到 LocalAppData 下，也可选择 D 盘等具有写入权限的位置。桌面快捷方式可选，系统应用列表提供卸载入口。安装包暂未代码签名。

更新前先退出 Space；选择原程序目录即可覆盖更新。安装和卸载只处理程序文件，保留个人数据库、备份、网盘连接和用户自行放入的其他文件。卸载不会清空个人数据。

## ZIP 更新

完整解压 `Space-2.3.3-Windows-x64-更新包.zip`，保留全部 DLL、data、模型及 native_assets.json。关闭旧程序后覆盖程序目录，不删除自己的配置或备份。

生产数据继续使用 `%APPDATA%\SpaceFlutter`，与安装路径分开。两种包均不含个人配置或业务数据。安装前核对同批 SHA256 校验文件。

本分支自动化测试和后台性能已记录；前台体验、帧耗时、实体打印等尚未全面验收，详见 verification/windows-2026-11-13/README.md。
