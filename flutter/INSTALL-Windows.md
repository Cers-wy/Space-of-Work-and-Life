# Space 2.1.0（13）· Windows

适用于 Windows 11 x64。下载 `Space-2.1.0-Windows-x64-Portable.zip`，完整解压至可写目录后运行 `Space.exe`。

请保留同目录的所有 DLL、data 目录和资源。无需安装额外 C++ 运行库；ZIP 已包含所需运行库。升级前退出旧版，再将新版完整解压到新目录。

继续沿用 `%APPDATA%\SpaceFlutter` 数据目录；安装包不包含用户数据库、令牌或恢复密钥。请从项目官方 Release 下载并核对 SHA256。

2.1.0 更新：设置六页重排，统一主界面材质和控件；关于页显示实际版本、作者、反馈邮箱及 GitHub 项目入口。打开设置时检查公开正式 Release，发现新版后通过浏览器下载，暂不支持在线热更新。应用图标保持不变。

跟随系统时，主界面的明暗切换只临时生效，系统下一次实际切换外观或重启应用后恢复跟随；设置中选择浅色/深色则固定使用该外观。

本地 SQLite 导出包含本机连接配置，请妥善保存；云端只保存加密任务数据，恢复前先备份本地。
