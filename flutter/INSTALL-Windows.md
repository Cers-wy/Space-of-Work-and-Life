# Space 2.2.0（14）· Windows

适用于 Windows 11 x64。下载 `Space-2.2.0-Windows-x64-Portable.zip`，完整解压至可写目录后运行 `Space.exe`。

请保留同目录的所有 DLL、data 目录和资源。无需安装额外 C++ 运行库；ZIP 已包含所需运行库。升级前退出旧版，再将新版完整解压到新目录。

继续沿用 `%APPDATA%\SpaceFlutter` 数据目录；安装包不包含用户数据库、令牌或恢复密钥。使用本地安装包前请核对同目录的 SHA256。

2.2.0 增加工具和发票台账。支持导入原件与附件、导出台账及合并打印。看板可设置显示的状态列。 Windows 合并 PDF 将票面和附件以图像嵌入，可直接打印。

跟随系统时，主界面的明暗切换只临时生效，系统下一次实际切换外观或重启应用后恢复跟随；设置中选择浅色/深色则固定使用该外观。

本地 SQLite 导出包含本机连接配置，请妥善保存；云端只保存加密任务数据，恢复前先备份本地。
