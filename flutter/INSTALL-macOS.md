# Space Flutter 2.0.3（4）

适用于 Apple Silicon（arm64）macOS。先退出当前 Space Flutter，打开 DMG，将 Space Flutter.app 拖到 Applications，并选择替换；也可解压 ZIP 后将应用放入“应用程序”。

继续使用现有 Flutter 数据目录，安装包不含任务数据库或云端凭据。需要迁移原生版任务时，请先导出 SQLite，再在新版设置中导入。

黑白主题均采用精细线性管理图标；导航展开与收起按钮在顶部左侧，侧栏与顶栏为完整圆角矩形。甘特图按状态显示清晰填色，默认排期保留虚线，仍支持整条平移、两端改期与撤销。主题色及毛玻璃、流光保持现有设置。

设置支持跟随系统、浅色与深色。GitHub 连接由用户填写，Token 与恢复密钥存入本机 SQLite；备份文件包含这些设置，请妥善保管。

本包使用本机临时代码签名，未做 Apple 公证。若系统阻止打开，可在“系统设置 → 隐私与安全性”确认来源后允许打开。

Windows 共用界面源码已更新，本次安装包为 macOS arm64；没有重新构建或实测 Windows 安装包。
