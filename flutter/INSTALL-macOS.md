# Space 2.1.0（13）· macOS

适用于 Apple Silicon（arm64）macOS。

- DMG：打开镜像，将 `Space.app` 拖入“应用程序”。
- ZIP：完整解压后打开 `Space.app`，也可将其拖入“应用程序”。
- 升级前完全退出旧版；旧名称为 `Space Flutter.app`。新版名称统一为 `Space.app`，请避免同时保留两个入口后混用。

沿用现有数据目录 `~/Library/Application Support/com.cers.space.flutter`，不需要迁移数据库。安装包不包含用户任务、令牌或恢复密钥。

本应用使用临时签名，未经过 Apple 公证。请从项目官方 Release 下载并核对 SHA256；系统首次打开提示可通过“系统设置 → 隐私与安全性”查看对应项目。

2.1.0 更新：设置六页重排，统一主界面材质和控件；关于页面显示实际版本、作者、反馈邮箱及 GitHub 项目入口，打开设置时检查公开正式 Release。发现新版后通过浏览器下载，暂不支持在线热更新。应用图标保持不变。

跟随系统时，主界面的明暗切换只临时生效，系统下一次实际切换外观或重启应用后恢复跟随；设置内选定浅色/深色后固定使用该外观。

本地 SQLite 导出包含本机连接配置，请妥善保存；云端只保存加密任务数据，恢复前先备份本地。
