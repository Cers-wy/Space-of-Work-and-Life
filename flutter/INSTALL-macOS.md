# Space 2.3.1（16）· macOS

适用于 macOS 12 或更新版本的 Apple Silicon Mac。打开 DMG，将 Space 拖到 Applications；也可完整解压同批 ZIP 中的 `Space.app`。升级前退出旧版。核对同批 `SHA256SUMS.txt`，应用版本应为 2.3.1（16）。

本包使用本地临时签名（ad-hoc），未做 Developer ID 公证。首次打开请按 macOS 显示的提示操作。

新版继续沿用 `~/Library/Application Support/com.cers.space.flutter` 的业务数据；分发包不包含演示数据、正式数据库、令牌或恢复密钥。请保留业务恢复备份。

本版发票合并保留原 PDF 对象，修复二维码和红章，双张自动上下均衡、单张靠上，支持指定票间距；发票详情“已报销”与项目选择框中线对齐。云端同步支持加密数据库和发票附件，新增 `.spacepack` 备份包。恢复数据前先导出本机备份。

性能、功能及平台验收状态以项目最新开发交接和同版本验证记录为准。Windows 由用户另行测试并手动发布。
