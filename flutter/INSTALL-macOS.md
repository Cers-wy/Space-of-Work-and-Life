# Space Flutter 2.0.8（9）

适用于 Apple Silicon（arm64）macOS。本次发布为免安装ZIP：完全退出旧版Space Flutter，完整解压ZIP后打开`Space Flutter.app`。也可将应用拖入“应用程序”文件夹以便长期使用；不需要运行安装程序。

继续使用现有 Flutter 数据目录，安装包不含任务数据库或云端凭据。需要迁移原生版任务时，请先导出 SQLite，再在新版设置中导入。

原生菜单及各级子菜单使用简体中文，修复“编辑”菜单中部分条目仍显示英文的问题。安装后请完全退出并重新打开应用，使系统重新加载语言资源。

数据库导入、导出的系统窗口及同名文件替换警告使用简体中文，包括存储为、标签、位置、取消和替换等文字。中文语言在应用启动阶段生效，不修改macOS全局语言；安装前请完全退出旧版并关闭其文件窗口。

图文说明按预览尺寸加载图片，保留原图用于保存与导出；关闭详情时释放预览缓存。图文编辑的修改判断减少重复序列化，卡片流光与绘制隔离保留原有逻辑。

黑白主题均采用精细线性管理图标；导航展开与收起按钮在顶部左侧，侧栏与顶栏为完整圆角矩形。甘特图按状态显示清晰填色，默认排期保留虚线，仍支持整条平移、两端改期与撤销。主题色及毛玻璃、流光保持现有设置。

设置支持跟随系统、浅色与深色。GitHub 连接由用户填写，Token 与恢复密钥存入本机 SQLite；备份文件包含这些设置，请妥善保管。

本包使用本机临时代码签名，未做 Apple 公证。若系统阻止打开，可在“系统设置 → 隐私与安全性”确认来源后允许打开。

Windows另提供同版本的Win11 x64免安装ZIP；Windows包新版回归与独立解压启动检查通过。本文件适用于macOS包。

看板每列右边缘可拖动调宽，松开吸附到1/2、2/3、3/4、1/1，双击恢复默认宽度；设置中的“隐藏滚动条”立即生效并在重启后保留。
