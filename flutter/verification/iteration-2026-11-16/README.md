## 已实现

- 工具模块与小工具新增、编辑、删除、隐藏恢复、卡片拖拽宽高、默认入口；SVG 随分块设置存入 SQLite，支持本地 HTML / 应用 / http(s) 网页。移除入口不删除目标文件。内置发票合并与文件管理可重新添加。

- 二次确认复用主界面 Glass，轻遮罩、主题与减少透明/动态策略一致；包括通用确认、发票三选、上传三选、状态迁移及 macOS/Windows 关闭请求。保留取消/放弃/等待上传的业务语义。
- 甘特固定开关与按状态烟雾设置已由先前提交 4f7c1eee 实现；本次接续未改该组源码。
