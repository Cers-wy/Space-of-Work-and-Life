# Space Flutter 2.0.1（2）界面改进验收

日期：2026-11-03。范围为用户提供的九项 Flutter 改进；改动前源码在 `work/backups/flutter-before-ui-20261103/`。

| 需求 | 结果 |
|---|---|
| 1. 常驻流光 | 可见卡片无需悬停即可播放，20Hz 更新；静态卡片内容独立缓存。后台、拖动和系统减少动态时暂停，保留当前光晕。 |
| 2. 卡片等高和单行省略 | 统一160逻辑像素，随文字缩放增加高度；项目位置预留，标题与说明各一行、禁止自动折行、末尾省略。 |
| 3. 分类与底部信息同排 | 分类、优先级、截止日期与完成按钮统一到底部一行，日期区域弹性截断。 |
| 4. 更多菜单层次 | 任务菜单改用独立表面、完整边框及阴影，浅色白底、暗色深紫灰底。 |
| 5. 标题框高度与留白 | 修正 InputDecorator 的实际边框高度，与下拉框均为40逻辑像素；文字居中，字段间距统一。测试直接测量实际装饰容器。 |
| 6. 清理标记内容 | 删除北京时间/甘特提示、“任务说明 / 可选”中的可选、加粗/下划线及图文提示工具栏；项目旁按钮显示“新建”。既有富文本格式仍可读取。 |
| 7. 粘贴图不进附件 | Quill图片钩子、系统剪贴板图像和图片文件粘贴均只生成说明内嵌图片；独立“上传附件”继续可用。 |
| 8. 项目管理 | 顶部文件夹入口可新建、改名、停用/启用、删除。停用项目保留历史任务、禁止新加入；编辑原任务可保持原项目。删除项目解除关联并保留任务，支持单步撤销。 |
| 9. 下拉层次 | 分类、状态、优先级、项目、排序等共用选项浮层及日期面板改用独立背景、边框和阴影。 |

项目停用状态随业务数据持久化：JSON项目的 `disabled` 字段、SQLite metadata中的 `disabledProjects`；旧数据库未含该字段时默认启用。Portable JSON保留停用状态；同一ID的项目名称或启停状态冲突时，合并拒绝静默覆盖。更老客户端不识别项目停用语义，本轮未执行跨旧客户端启停同步。

验证结果：

- 60项核心、存储和组件交互测试通过，见 `ui-improvements-tests.log`。包括三种图片粘贴路径保存重开、附件为空，项目启停/改名重开及删除撤销。
- 双主题、1020/1180/1380/1600宽度下四视图与导航收展无布局异常；1020×640紧凑表单与下拉浮层通过。结构截图在 `screenshots/`。
- 静态检查无错误；保留项目既有的3条Quill实验API提示和1条schedule风格提示，见 `ui-improvements-analysis.log`。当前SDK对中文工程路径的LSP消息解析异常，因此在临时英文路径的同内容代码副本执行分析。
- macOS arm64 Release 2.0.1（2）构建完成，分发副本 `codesign --verify --deep --strict` 通过；ZIP附SHA256。见 `ui-improvements-macos-build.log`。
- 新二进制使用隔离合成数据启动到Space窗口，桌面工具响应过慢，未执行完整原生窗口交互。图片粘贴证据为真实Flutter编解码与模拟桌面桥接回归，不宣称系统剪贴板实机验证。

交付：`output/flutter/Space-Flutter-2.0.1-macOS-arm64.zip`。共用Flutter代码已更新；本轮未重建或实测Windows安装包，原2.0.0包保留。未测本轮常驻流光的CPU/帧耗时，因此此前悬停播放版本的前台静止CPU结果不适用于当前版本。
