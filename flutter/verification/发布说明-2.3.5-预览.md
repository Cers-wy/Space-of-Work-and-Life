# Space 2.3.5（22）功能预览

本次提供 macOS universal DMG / ZIP 与 Windows x64 便携更新包，源码来自 main 的 `bedb07fcab8584682bb2e21fadeb585ee0125f54`。这是待用户体验的预览版本；2.3.4 正式下载入口保留。

## 新功能与使用入口

- **工具工作台**：顶栏“添加模块”“编辑卡片宽高”“恢复隐藏模块”均为图标按钮；每张卡片右上角菜单可添加小工具、编辑模块、隐藏或删除。编辑布局后拖动右下角手柄，松手保存宽高；窄窗口不改已保存的宽窗口列宽。模块设置可指定整卡默认入口。
- **自定义工具**：支持浏览器 http(s) 网页、本地 HTML 与应用入口；可上传 SVG 图标，图标随设置持久保存，不依赖原文件路径。移除入口不删除目标文件。内置发票合并和文件管理可重新添加。
- **发票识别**：改进购销方名称与税号的标签、上下/左右、竖排归属；PDF 按页独立解析，缺购销方信息时继续本地 OCR。铁路区分开票日期与乘车日期，航空使用填开日期、填开单位和明确合计。多张不同票号的 PDF 提示拆分，附件不补入另一票面。
- **发票详情**：长销售方名称单行整行显示，其余字段以两列为主；报销项目占半宽，右侧保留是否报销。项目可搜索选择或输入新名称，保存发票时才创建项目，取消不创建。
- **甘特图**：工具栏固定开关控制左侧项目信息是否随时间轴横向滚动，并保存选择。
- **任务卡片**：紫色烟雾覆盖卡片内部上下左右漂移；“状态与分类管理 → 任务状态”提供每个内置/自定义状态独立的圆形烟雾动画开关。默认开启，关闭不绘制并停止相应刷新；离屏、失焦、减少动态效果策略继续生效。
- **确认弹窗**：统一主题玻璃材质及轻遮罩，包括删除/恢复等通用确认、发票三选、上传退出三选、状态迁移及两端关闭确认。系统文件选择器保持系统样式。
