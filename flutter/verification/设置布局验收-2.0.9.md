# Space 2.0.9 设置布局验收

2026-11-04。按用户确认的效果图实现，与导航展开／收起修复合并到 2.0.9（10）。本文件记录设置改版的功能范围；双平台最终构建、性能数据和分发状态以同版本总验收记录为准。

## 当前实现

- 设置窗口最大 1400 × 940，左侧分类导航，全部设置采用双栏：左栏为外观、本地备份和数据管理，右栏为 GitHub 私有仓库同步。内容宽度不足 720 时改为单栏滚动；窗口宽度不足 760 时分类导航使用带提示的图标。
- 浅色使用清晰的白色卡片和细边框；深色保留当前紫色强调色。三张主题预览卡片、控件间距、输入边框与操作层级统一。页头关闭、底部完成和分类导航始终位于可见区域。
- 分类采用可中断的 300ms 透明度过渡；系统减少动态效果时立即切换。保留分类内容的状态，隐藏部分排除焦点和动画，切换分类与调整窗口不会销毁同步输入控制器。
- SQLite 四项操作为两行两列；载入演示任务与清空任务分行，清空前保留确认，取消不改任务。沿用数据库导入校验、自动备份、云同步上传／恢复确认等规则。
- Token 和恢复密钥默认隐藏，输入中的内容可分别显示／隐藏；已保存状态与最近同步时间独立展示。失败反馈不使用历史同步成功的绿色状态。
- `SpaceInput` 仅新增可选 `borderColor` 参数供设置表单使用，其他调用未传参时仍使用原有输入边框和焦点样式。分类透明度使用同一控制器及其派生动画，避免重建时重复创建曲线监听器。

## 设置性能计划与本轮跳过状态

按2026-11-05用户快速收尾指令，本节设置性能场景本轮未执行，不将下表视为测试通过。

新增 `tool/settings_performance.dart`，统一用于 2.0.8 基线和最终合并版，Release 构建、120 项合成任务、相同默认窗口与浅色初始主题。必须维持前台，无构建／测试并行干扰。

| 场景 | 操作与时长 | 对比口径 |
|---|---|---|
| 设置打开与关闭 | 6 次打开／关闭 | 相同脚本，记录 CPU、RSS、帧耗时与程序触发至下一 Flutter 帧时间 |
| 设置静置 | 5 秒 | 两版相同条件 |
| 分类切换 | 10 次，含返回全部设置 | 新场景，2.0.8 无分类，不虚构基线 |
| 设置滚动 | 8 次顶／底往返 | 记录各版滚动范围，布局不同导致距离不同 |
| 主题切换 | 6 次浅／深切换 | 两版相同操作，最终版在外观分类执行 |
| 关闭后静置 | 3 秒 | 检查设置关闭后的持续开销 |

最终 `report.json` 记录版本、环境、任务数、窗口、CPU、RSS、采样时长、帧耗时／超预算帧及操作响应。场景文件由公共探针写入；附加的程序触发至下一帧时间与滚动范围保存在最终 `report.json`。原生输入到屏幕呈现延迟及真正掉帧数量不可由这些指标推算。

本轮不重复与设置／导航无关的图片缓存、图片打开关闭性能场景，沿用 `验收记录-2.0.8.md` 与 `performance-2.0.8/` 的有效结果。真实多设备云同步不属于此次布局改动的性能验证；既有协议与恢复规则通过隔离自动回归检查。Windows 虚拟机结果必须明确标注环境，不能视为原生 x64 硬件流畅性验收。
