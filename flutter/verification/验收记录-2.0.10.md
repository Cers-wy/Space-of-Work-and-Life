# Space 2.0.10（11）验收记录

2026-11-05。本轮按用户指定范围实施四项变更，性能验证只覆盖甘特图与日历月视图。macOS arm64 和 Windows x64 使用相同19个运行时 Dart 文件，哈希见 `source-2.0.10-sha256.json`。

## 交付行为

1. 甘特图取消左上角图标、标题和旧14天文字；右侧提供日／周／月刻度、年月选择、上一月和下一月。默认时间范围为当前整月，日刻度可横向滚动；到达边缘后继续横向滚动切换相邻月份，普通纵向滚动不切月。按与当月相交的排期显示任务，保留拖动和撤销。月份文字淡入淡出，减少动态效果时立即切换。
2. 状态、优先级、分类、截止日期和项目支持多选；同条件取并集，不同条件与关键词组合。可保存当前条件及排序为启动默认配置，也可重置默认或清除本次筛选；失效引用自动清理。
3. 状态与分类在同一面板切换配置。内置分类可改名，也可新增分类；稳定标识保留任务关联，分类定义随SQLite、便携备份和云端恢复保存。长名称在卡片、列表、甘特及日历清单内省略，避免撑破布局。
4. 月格按可用高度计算任务条数，取消最多3项的上限；超出时预留剩余数量加“…”的提示。点击日期查看完整事项。600任务、1380×860示例中月格从1条增加为2条；增高窗口可显示超过3条。日期索引缓存最多保留两个可见月区间，筛选结果或日期变化时失效。

## Mac本轮实测性能

Apple M5、10核、16GiB、Mac17,2、macOS 27.2，arm64 Release，Flutter 3.47.9／Dart 3.13.7。600项隔离合成任务、暗色、默认1380×860窗口、120Hz。基线为2.0.9运行时代码，最终为本版源码；两端未读取正式数据。场景全程Flutter生命周期为resumed。报告在 `performance-2.0.10/macos-before.json` 和 `macos-after.json`，真实引擎截图在同目录。

CPU 100%表示一个逻辑核；RSS为场景末驻留内存，耗时单位ms。基线甘特展示旧14天，本版展示整月，月历也增加可见任务，因而并非相同绘制量。下表为单次短样本观察，不代表统计显著性或普遍节能结论。

| 甘特静置 | 3.009 | 0.33 → 0.00 | 130.45 → 129.55 | 静置无采样帧 | 静置无采样帧 |

甘特滚动构建或栅格超过8.33ms预算的采样帧由36/221变为2/287；该指标不是屏幕实际呈现掉帧数。日历切月构建P95增加，栅格P95下降，本版首帧响应P95为30.77ms；甘特跨月/刻度切换首帧P95为27.85ms。月历切月仍有4/18个阶段帧超过预算，不宣称每帧120Hz达标。静置没有持续采样帧，不能将表中无帧解释为0耗时或无限帧率。原生输入至屏幕呈现的端到端耗时和真实掉帧数未采集。此前失焦或未完成的探针样本已排除，未纳入对比。
