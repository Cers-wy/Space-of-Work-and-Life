# Space 2.3.3 发布说明

发布版本 **2.3.3+20**，源码提交见 Git 标签 `v2.3.3`。

## 本次新增

### 发票批量更新

- 台账选中多张发票后，标题栏的「批量更新发票」可一次修改**报销月份、报销项目、个人备注**。
- 只提交填写过的字段，留空项保持原值；月份必须是有效 `YYYY-MM`，项目必须仍存在于当前项目列表，任一校验失败整批不写入（单事务）。
- 弹窗期间被删除的发票自动跳过，并在结果中只统计实际更新的张数。
- 后台批量识别进行中也可以正常修改报销字段；迟到的识别结果不会覆盖你刚保存的月份与备注。

### 窄窗口标题栏

- 发票、工具、上传记录页的标题栏在窄窗口改为横向滚动操作区，不再挤压标题或溢出。

### 识别精度

- 价税合计只在明确的「价税合计／小写」标签后取值，单独的「金额」作为兜底且必须独立成行，避免把未税金额或明细金额误当成合计。

### 修复

- **任务看板模式点击「筛选」时整窗闪一下**：筛选、发票筛选、文件筛选三个浮层不再给整个窗口加压暗遮罩（此前浅色主题会瞬间压暗约 17%，暗色主题不压暗，表现不一致）。逐帧实测整窗平均亮度由 `243.80 → 202.33` 变为 `243.80 → 242.95`，压暗消失。

## 使用入口

| 功能 | 入口 |
| --- | --- |
| 批量更新发票 | 发票台账勾选多张 → 标题栏「批量更新发票」 |
| 批量识别 | 发票台账勾选多张 → 标题栏可识别图标（后台串行，前台可继续操作） |
| 筛选与排序 | 任务页标题栏筛选图标，或 `⌘F`（概览收起时） |

## 平台与验证范围

- **Windows**：`Space-2.3.3-Windows-x64.zip`，x64 Release 便携包，解压后运行 `Space.exe`，详见包内 `使用说明.md`。由 GitHub Actions 在 `2.3.3+20` 源码上编译，包内已核对 `Space.exe`、`pdfium.dll`、ONNX Runtime、OCR 原生辅助库与四个固定 OCR 模型。**未在 Windows 实机做功能与性能验证**，需用户自行运行确认。
- **macOS**：本次未产出分发包。本机 Xcode 27.2 的 `xcodebuild` 包解析被系统拒绝（`sandbox-exec: sandbox_apply: Operation not permitted`），`flutter build macos` 与直接调用 `xcodebuild` 均失败，未构造也未上传 macOS 资产，不能视为 macOS 已验证。
- **自动化测试**：本轮受影响范围定向执行，`filter_hotfix_test`＋`workspace_test` 31 项、`invoice_batch_update_test`＋`invoice_recognition_test` 14 项全部通过；`dart analyze lib test tool` 仅保留 3 条既有 Quill 实验 API 警告。
- **性能与资源**：未取得有效前台样本。三轮 Profile 实测均因窗口失焦被标记为后台样本，不能作为前台流畅性证据；本轮不记录为性能通过。识别相关的内存峰值（RSS 约 1.0–1.33 GB）已在探针数据中记录，供后续专项核查。
