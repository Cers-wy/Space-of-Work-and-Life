# Space 2.3.4（21）

本次整合 macOS 改进与 Windows 优化分支，macOS 提供 DMG / ZIP；Windows 同步最新功能源码与版本，本轮未生成新的 Windows 安装包。

## 新增与改进

- **发票分页查询**：每页 50 张，上一页/下一页切换，减少大量发票时的加载和滚动开销。关键词、报销月份、项目与状态查询仍覆盖全部记录；月份选项来自全库，完整筛选结果导出不受当前页限制。翻页会清空本页勾选，避免误操作。
- **批量更新报销信息**：勾选本页发票后，点击标题栏的编辑图标，统一设置报销月份、项目和备注。只有填写的字段才更新，留空保持原值。月份格式与项目有效性会校验。
- **识别后直接落库**：票面识别成功直接保存有效字段；批量识别使用独立后台队列，仍可筛选、勾选、编辑、导入及切换页面。识别期间新保存的手工字段及删除操作受到保护。
- **筛选交互修正**：任务看板、发票与文件筛选沿用现有玻璃风格，避免浅色模式打开筛选时整窗明显变暗闪一下；标题栏按钮保持纯图标，悬停或点击显示提示。
- **文件管理合页**：文件与上传记录使用同页标签，路径与上传状态位于标签右侧；名称、单日、十类文件类型多条件查询。文件页设置直达全局网盘设置，关于始终位于设置末尾。
- **保留 Windows 优化**：合并昨晚分支的备份 ZIP 输入/输出流同步释放修复，以及允许自定义路径、保留个人数据的 Windows 安装器源码。安装器版本与共用源码同步为 2.3.4；本轮未构建或实机验证新 Windows 包。

## 验证与性能

本轮 28 项新增/受影响定向用例通过，macOS Debug、生产 Release 编译和包检查记录见 [本轮 macOS 验证](macos-2026-11-14/README.md)。未对未改动模块做全量回归。Windows 历史记录保留，不能代替新增分页的 Windows 验收。

Apple M5 / 16 GiB、macOS 27.2.1、Profile 前台实测：1000 张库存滚动构建 p95 从约 107 ms 降至 3.3 ms，该滚动场景未出现单阶段超预算帧；后台识别期间构建 p95 约 4.3 ms。OCR 后空闲采样末端 RSS 约 192 MiB。翻页、文件列表切换和个别弹窗仍存在低频帧耗时尖峰，不宣称全部交互零掉帧。

上传场景完成真实本地扫描、摘要、编码及队列持久化，但远端接口为模拟，不代表真实网速。合成图片金额覆盖为 0/8（安全留空），票号及个人月份保护通过；不把留空记为金额识别精度通过。详细环境、原始数字、样本有效性与限制均在验证记录中。

## macOS 安装

下载 [DMG](https://github.com/Cers-wy/Space-of-Work-and-Life/releases/download/v2.3.4/Space-2.3.4-macOS-universal.dmg) 或 [ZIP](https://github.com/Cers-wy/Space-of-Work-and-Life/releases/download/v2.3.4/Space-2.3.4-macOS-universal.zip)，退出旧版后将 `Space.app` 放入 Applications。通用包包含 arm64 / x86_64；实测为 Apple Silicon，未做 Intel 实机验证及 Apple 公证。使用本地 ad-hoc 签名，校验见 Release 附件 `SHA256SUMS.txt`。
