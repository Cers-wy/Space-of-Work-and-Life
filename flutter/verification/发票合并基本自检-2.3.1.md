# 2.3.1 发票合并基本自检

日期：2026-11-12。版本：2.3.1+16，开发分支 `codex/space-2.3.1`，修改前基线 `9e08bcbe`。范围为源码预览前基本自检，**不是正式发布验收**。

## 已实现

- 双张自动分配上下余量到票间，上下各按设置边距；单张和末页单张靠上，同来源跨页不跳尺寸。
- 默认四边 10 mm、自动票间距；可切换指定数值。自动模式显示实际行间距；单行直接靠上。裁剪线位于实际间隙中点，单张不显示空位裁剪线。
- 两端共用 PDFium 8125 做可见页面检查、裁边、渲染、原 PDF 对象导入和保存。二维码、章及透明蒙版不经过 Quartz 重绘或整页栅格化。
- 逐票等比适配；混合票型同行顶部对齐；附件沿用独立页。无效设置保留有效预览并禁止输出。
- UI 沿用现有玻璃和控件，指定间距输入区轻量展开，减少动态效果时直接显示静态内容。
- 同轮修复发票详情已报销与项目对齐：保持32高圆形勾选控件，在40高区域垂直居中，与项目选择框中线一致；增加中线及字段高度断言，浅色/深色/窄窗口复核通过。

## 用户源码预览

VS Code 打开项目 `flutter` 目录，选择已有「Space Dev (macOS, 演示数据)」并按 F5。本轮有原生依赖及桥接修改，**首次须停止旧进程并完整重启**，仅按 r 热重载不足以加载新库；之后仅 Dart 界面修改可热重载。

先用发票1、发票2查看自动双张间距、二维码与红章；切换指定间距，再移除一张核对顶部位置，最后试1～4张/页、一式两份和保存。预览使用独立数据目录，不修改正式数据库。
