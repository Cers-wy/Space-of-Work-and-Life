# Space 2.3.2（19）

本次更新完善发票识别与跨电脑文件管理，减少重复保存，让后台任务与日常操作同时进行。

## 发票识别与批量操作

- **识别后自动保存票面信息**：在发票详情点击识别，成功后直接更新台账，无需再点保存。个人备注和报销信息继续由用户维护；识别不会代填这些字段。
- **后台批量识别**：在发票列表勾选多张发票，点击标题栏识别图标即可启动后台队列。底部展示进度，识别期间可继续筛选、勾选、编辑、导入和切换页面。
- **支持批量删除**：勾选后点击删除图标，确认后删除对应发票原件和关联附件。识别期间删除的记录不会被迟到结果恢复。
- **保护手工修改**：后台识别期间已保存的手工字段优先保留；部分发票识别失败时，其余发票继续处理，并保留失败项供重试。
- **本地识别**：电子 PDF 优先读取文本层；图片和缺少文本的 PDF 使用内置 PP-OCRv6，必要时采用增强档识别。发票识别不上传云端，也不在正常使用中下载模型。复杂、模糊或手写票据仍需核对结果。

## 文件管理与上传记录

- 原“文件网盘”统一改名为 **文件管理**，与 **上传记录** 合并为同页双标签。切换页面后，上传仍会继续。
- 工具首页的文件管理卡片支持整卡点击进入列表，也可直接拖入文件或文件夹上传；保留独立上传入口。
- 文件列表增加任务模块同款筛选面板：文件名称、单日创建日期、文件类型多选，日期和下拉控件沿用一致的宽度及布局。
- 文件类型覆盖 Word、Excel、PPT、PDF、压缩包、视频、图片、文本、应用程序和其他，按常见扩展名归类。
- 文件路径移至标签右侧；上传状态筛选也与标签同一行排列，窄窗口自动调整布局。

## 设置与交互

- 仓库链接、分支、来源设备和令牌统一在 **设置 → 网盘设置** 维护。文件管理右上角的设置图标可直接定位到该栏目；凭据继续保存在本机系统安全存储。
- **关于 Space** 始终为设置最后一栏。
- 标题栏统一纯图标按钮，鼠标悬停或点击显示操作提示，并提供无障碍名称。
- 发票详情移除重复成功提示，报销项目保持半列宽度，保留当前玻璃材质、浅色及暗色主题。
- 修复 macOS 钥匙串读取占用主线程导致启动界面阻塞的问题；主界面先显示，网盘异步初始化。
