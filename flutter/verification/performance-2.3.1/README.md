2026-11-12；应用代码 `43884e7b`，修改前基线 `9e08bcbe`，均为2.3.1+16。Apple M5、16GiB内存（Mac17,2），macOS 27.2.1 (26B131)、arm64、Flutter 3.47.9 / Dart 3.13.7、Xcode 27.2，Release / Metal Impeller。内容区1380×828，60Hz。

同一独立探针 `tool/invoice_performance.dart` 分别构建基线与当前源码。隔离数据：9条示例任务、用户给定的两张PDF交替复制为100个独立文件。不访问正式数据库，私人PDF未上传Git。

## 结论与限制

- 首次实测发现1800px逐像素裁边产生大量对象，100票约5.9秒。已改为900px原生BGRA缓冲扫描，无中间RGBA复制；修复后比同条件基线快约28%–29%。票面直接复制原PDF对象，保留二维码、印章及蒙版数据。
- 100票导出增加约29–35ms，CPU约单核100%，只持续约0.37秒。当前输出保留原始PDF对象与透明蒙版，属于保真成本。
- 双票首次预览增加约65–76ms；单次排版切换平均186.7–187.9ms，基线136.6ms，均含100ms输入防抖。当前合并预览1600px、详情1200px，相比旧880px显示更多细节，预览成本有所上升。处理在串行工作Isolate进行。
- 当前有帧场景的build p95最大14.74ms、raster p95最大8.094ms；两轮所有场景的单阶段超过16.67ms帧计数均为0。该指标不是物理掉帧率，未取得显示器实际呈现/丢帧计数。
- 连续开关详情10次后RSS约152.5–153.8MiB；100票导出后15秒约179.3–212.4MiB，低于各轮导出后的226.1/214.0MiB。短轮次未见持续累积，不据此声称长期无泄漏。
- Dart main到首帧：基线106.7ms，当前76.5–121.3ms。单次基线、两次当前，不等同于操作系统冷启动，不能据此断言启动提升。
- 独立的任务/Gantt/日历大量数据性能未受本次PDF与详情对齐修改影响，沿用 `verification/performance-2.0.10/macos-before.json`、`macos-after.json` 及 `验收记录-2.0.10.md`，不写成本轮实测。
- 本轮全量自动化回归163项通过；静态分析仅3条既有Quill experimental_member_use警告（dialogs.dart:259–260），无新增警告。
- Windows仅CI Release编译、包结构及校验通过。按用户指示，Windows功能、性能、资源及实际启动均由用户后续测试并手动发布，不标记双平台验收完成。未做实体打印扫码、Intel Mac与长时间压力测试。

## 复测

用 `flutter build macos --release --target tool/invoice_performance.dart --dart-define=SPACE_PROBE_VERSION=<commit>` 构建。设置 `SPACE_FLUTTER_DATA_DIRECTORY=<全新隔离目录>` 和 `SPACE_INVOICE_PROBE_INPUT=<含发票1.pdf、发票2.pdf的目录>` 启动二进制，全程保持前台。该入口使用macOS AppKit，不适用于Windows。

测后必须重新执行 `flutter build macos --release --target lib/main.dart`，禁止分发探针构建。正式包启动、隔离数据及资源烟测见同目录 `macos-package.json`。

正式DMG只读挂载后实际启动生产入口，以全新隔离数据库预热5秒，随后前台采样10.41秒、40次全部通过PID前台核验。稳定空闲CPU约0.096%，RSS 127.27–128.13MiB。该包无性能探针开销，因此不与探针空闲值直接比较。先前外部烟测脚本未加载AppKit，前台检测无效；修正后重新测量，之前数据全部作废，未用于本报告。ZIP CRC、DMG校验、ad-hoc深度签名、最低macOS12及真实启动均通过。
