# Space Flutter 2.0.10（11）

Space 是使用 Flutter/Dart 共用业务与界面的本地桌面工作台，支持 macOS Apple Silicon、Windows 11 x64。包含任务、项目、自定义状态、看板、列表、甘特图、日历、图文附件、SQLite 备份及 GitHub 加密同步。

## 界面与操作

界面使用系统可用的苹方字体及回退字体，支持跟随系统、浅色、深色。保留玻璃表面、柔光、卡片流光和减少动态／透明度适配。侧栏与概览分别收展，导航图标以同一实例连续移动，文字独立淡入淡出；顶部操作行始终占满可用宽度，概览下方内容独立过渡。窗口最小1020×640，不包含移动端布局。

看板列右边缘提供调宽指针与高亮线：拖动实时预览，松开吸附到1/2、2/3、3/4、1/1，双击恢复1/1。各列独立保存比例；默认列宽根据窗口、导航及状态数重新计算，再应用比例，保留列间12px间距与横向滚动。卡片等高，项目、标题、说明单行省略，窄列元数据分两行，完成、新建及排序入口保留。任务跨列拖动、列排序和排期拖动使用独立交互区域。

甘特图入口与标题共用三段错位圆端横条图标；全部展开／收起使用向下／向上双折角，图标20px、按钮40px，并根据当前项目收展状态禁用。项目行保留单折角。甘特图默认查看当前整月，支持日／周／月刻度、年月选择和横向边缘滚动切换相邻月份；保留整条及两端拖动、撤销。

全部滚动区域使用4px细滚动条，悬浮或拖动时6px，自动淡出且可拖动定位。设置提供默认关闭的“隐藏滚动条”：开启后横向与纵向滚动条均不显示，已打开的弹窗立即响应；滚轮、触控板、键盘及内容滚动继续可用，选择随SQLite保存。

任务分类支持新增和编辑，与任务状态在同一管理面板配置；任务还支持优先级、项目、开始与截止日期、状态、富文本及附件。状态、优先级、分类、日期和项目可多选，同条件取并集、不同条件组合生效，可保存为启动时的默认筛选配置；完成状态唯一，重开回待办，业务修改支持单步撤销。项目可改名、启停、删除并保留任务；状态可创建、启停、迁移删除及重排。日历支持日／周／月及当日新建；月格按可用高度显示任务，剩余任务用“数量…”标识，点击日期可查看完整清单。

图文预览按显示尺寸和像素密度解码，保留原图；关闭详情时释放预览缓存。macOS 菜单、数据库文件面板和覆盖警告使用简体中文，语言仅设置在应用偏好域。

设置使用左侧分类导航与右侧自适应双栏，组织外观、本地备份、云端同步与数据管理。分类切换保留未完成的连接输入，支持密码显示切换与键盘操作。

## 数据

macOS：`~/Library/Application Support/com.cers.space.flutter`；Windows：`%APPDATA%\SpaceFlutter`。更新包沿用原Flutter数据库，不含用户数据库或凭据。原生版数据需由用户导出SQLite后在设置中导入。

本地数据事务保存，包含修订冲突检查与上一份快照；设置提供SQLite导入、导出与恢复。协议读取JSON V1～V6及SQLite1～3。GitHub手动同步与恢复使用AES-GCM加密；Token、恢复密钥和连接配置仅保存到本机SQLite，本地导出备份包含这些配置。旧Base64密钥保留V1兼容，新恢复口令使用PBKDF2和AES-GCM V2。

验收只使用合成数据；`SPACE_FLUTTER_DATA_DIRECTORY`可指定独立测试目录。正式分发不包含演示编译参数。

## 构建与验证

已使用Flutter 3.47.9／Dart 3.13.7，依赖由`pubspec.lock`锁定。在本目录运行：

```sh
flutter pub get
flutter test --reporter expanded
flutter build macos --release
python3 tool/package_macos.py
# Windows开发环境：
flutter build windows --release
```

macOS打包脚本生成ZIP、DMG、SHA256，已有同名目录时停止。Windows免安装包须完整保留Release目录及C++运行库、SQLite和Flutter资源。详见[macOS安装说明](INSTALL-macOS.md)、[Windows使用说明](INSTALL-Windows.md)。macOS为临时签名，未做Apple公证。

当前验证范围与限制见[本版验收](verification/验收记录-2.0.10.md)。本轮仅进行甘特图与日历月视图的性能测试；筛选与分类进行相关功能验证。

## 目录

- `lib/core`：模型、SQLite、图文与加密协议；`lib/ui`：共用桌面界面。
- `macos`、`windows`：Flutter桌面平台桥接；`linux`保留runner。
- `test`：可重复执行的回归代码及合成协议样本；`tool`：构建、打包与验收工具。
- `verification`：当前发布验证记录；依赖许可见`THIRD_PARTY_NOTICES.txt`。
