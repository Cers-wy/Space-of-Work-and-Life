# 跨平台开发说明

## 1. 实现目标

在目标桌面操作系统实现本仓库文档所描述的Space。界面、特效、业务和数据协议均分别验收；页面使用相同任务数据、查询条件和提交入口。

先阅读[当前功能说明](01-当前功能说明.md)和[界面与特效说明](02-界面与特效说明.md)，再实现数据与同步。技术栈可按目标平台选择原生或成熟跨平台桌面框架，需满足低空闲开销、清晰中文、精细图标、文件交互和可靠持久化。

## 2. 获取与构建

```sh
git clone https://github.com/18390208101/Space-macOS-native.git
```

macOS需要macOS 14+及Xcode/Swift工具链，从仓库根目录执行：

```sh
zsh native/scripts/test.sh
zsh native/scripts/build-app.sh
```

应用输出到`output/Space.app`。SwiftUI/AppKit界面代码需要在其他操作系统使用对应桌面技术实现；数据、查询、排期与加密规则可依照文档独立实现。

## 3. 模块划分

| 模块 | 职责 | 输出 |
|---|---|---|
| 领域模型 | 任务、状态、项目、附件、时间、查询、排期 | 可测试的纯业务逻辑 |
| 数据仓储 | SQLite、事务、快照、revision、导入校验 | 一致持久化及恢复能力 |
| 应用状态 | 查询、草稿、缓存、单步撤销、提交、错误提示 | 四视图共用状态 |
| 界面层 | 工作台、四视图、表单、统一控件与主题 | 可操作页面和特效 |
| 富文本适配 | 普通文本镜像、格式、内嵌图、RTFD | 跨平台显示、编辑、导出 |
| 同步编码 | portable、指纹、AES-GCM、SP信封 | 与macOS兼容的载荷 |
| 同步传输 | GitHub、HTTPS/WebDAV、目录 | 带冲突保护的上传下载 |
| 安全存储 | 令牌、恢复密钥、访问密码 | 系统凭据存储接口 |
| 打包 | 安装、架构、版本、签名、许可证 | 目标平台可运行产物 |

业务入口建议覆盖validateTask、applyQuery、resolveSchedule、changeStatus、saveTask、savePreferences、exportSnapshot、readBackup、seal/unseal和resolveSyncDecision。看板、列表、日历和详情调用同一套状态变更规则。

## 4. 实现任务

| 阶段 | 工作 | 完成条件 |
|---|---|---|
| 1 基础控件 | 字体、颜色、玻璃、按钮、下拉、日期、侧栏轮廓 | 亮暗主题和焦点/禁用态准确；最小窗口可用 |
| 2 领域与数据 | 字段校验、日期、状态、查询/排序、排期、SQLite与备份 | 边界测试通过；写入失败不覆盖 |
| 3 工作台 | 导航、概览、快筛、看板、列表、任务表单、项目与状态 | 增改删、撤销、拖动、键盘、重启保存通过 |
| 4 图文附件 | 加粗/下划线、光标插图、上传、预览、另存、RTFD | 真剪贴板和跨平台图文往返保留内容与字节 |
| 5 甘特与日历 | 项目层级、14天、端点裁剪、拖动、日/周/月、更多 | 默认日期不写库，改期只提交一次，跨日正确 |
| 6 同步 | 编码与加密、安全存储、GitHub状态机、SP合并 | 密钥/哈希/版本/双边冲突均有正确保护 |
| 7 界面与资源 | 多宽度、多DPI、特效、滚动、辅助功能 | 同条件截图与实际交互分别通过 |
| 8 分发 | 安装/升级、架构、签名、运行依赖、说明 | 干净系统可运行且保留用户数据 |

## 5. 系统能力适配

| 能力 | 实现要求 |
|---|---|
| 毛玻璃 | 保留底层柔光、半透明面板、亮边、卡片层次；降低透明度使用实底 |
| 中文字体 | 使用合法可用字体；核对字重、行高、文字宽度及裁切 |
| 矢量图标 | 统一描边、光学尺寸、基线和命中区，匹配各功能语义 |
| RTFD | 能正确显示/编辑/回写文字格式和图；无法编辑时保护原字节并明确能力 |
| 凭据 | 采用系统安全存储，不能写入SQLite、日志或同步载荷 |
| 文件对话框 | 取消不修改，权限与路径错误可见，支持中文文件名 |
| 文件预览 | 图片/文本等提供可用预览，其他类型至少支持另存 |
| 进程锁与快照 | 进程间互斥、revision冲突检查、SQLite一致快照含WAL |
| 快捷键 | 映射为平台主修饰键，帮助与界面文案一致，输入法组合输入不被劫持 |

## 6. 数据隔离

开发与验收使用独立应用ID、目录和合成样本。真实同步测试使用专用私有测试仓库或路径，不能覆盖用户正式任务备份。

用户数据放在系统用户级应用数据目录，设置页显示实际路径。安装和升级只替换程序；删除用户数据需要明确操作。自动化不读取正式数据库、钥匙串或本机同步配置。

## 7. 特效与性能检查

空闲不为所有卡片持续启用帧时钟；悬停只刷新单卡光效；拖动坐标由独立状态处理；日期检查仅跨日发布更新；切换主题只改偏好，不重写附件；恢复数据不形成循环上传。

在空库、常见任务量和1000任务下，分别测冷启动、空闲、悬停、拖动、视图切换及附件保存。记录设备、系统、架构、DPI、窗口尺寸、任务/附件规模、时长和工具；CPU、内存与交互时延分开说明。

## 8. 交付与验收

- 源码、构建命令、SDK/运行库、自包含情况及许可证。
- 目标平台安装/便携产物、架构、版本、签名状态和SHA256。
- [190条验收](05-验收用例.md)各项结果、执行环境、证据位置。
- 亮暗四视图、导航/概览状态、弹窗、筛选、日期、空态和错误态截图。
- 1020/1180/1380/1600逻辑宽及目标系统常用缩放的检查。
- 真实拖动、中文输入、快捷键、文件选择、剪贴板图片、预览、退出重启测试。
- macOS与目标系统往返的图文、附件哈希、项目顺序、状态、排期、完成时间与同步结果。

## 9. 开发执行指令

> 请在指定目标桌面系统实现Space，完整遵守docs中的当前功能、界面和特效、数据、同步及验收说明。先实现统一主题与基础控件，再实现共享领域模型和仓储，随后完成四视图、任务/项目/状态、富文本附件和两套同步。使用隔离目录与fixtures样本；所有写入保持字段完整、先验证、事务提交、冲突停止。按190条用例逐项记录结果，分别提供功能、视觉与跨设备互通证据，交付真实可运行安装产物及构建说明。
