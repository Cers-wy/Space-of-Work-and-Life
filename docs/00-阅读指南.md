# Space 软件说明阅读指南

Space 是一个用于管理工作、个人事务和生活事项的桌面工作台。同一份任务数据可以通过看板、列表、甘特图和日历查看和维护，支持本地备份及加密同步。

## 界面效果

主窗口采用紧凑的岛式布局：左侧导航、顶部概览和任务区域分别拥有玻璃表面，四周与区域之间留出小间距。导航和概览各自独立收起。

明亮主题以冰蓝、柔白和奶白为主，暗色主题以黑灰玻璃叠加紫色环境光，文字和操作使用亮紫色强调。任务卡同时保留内部柔光和四周光边；悬停时光效缓慢运动，空闲时保持静态，拖动和应用失焦时停止持续动画。

主题、视图、筛选、任务表单与状态管理使用一致的控件语言：8逻辑点矩形圆角、细致图标、清楚的焦点/选中态、中文提示和紧凑按钮。日夜开关采用胶囊和圆形选中区域。

## 使用方式

了解软件时先阅读功能与界面两份说明。开展其他平台实现时，再阅读数据和同步协议，使用fixtures合成样本检查互通，按验收用例记录结果。

本文档中的功能均按完整当前行为描述。JSON V1～V6与SQLite格式编号用于文件读写兼容；产品当前版本信息在应用元数据中查看。

## 项目内容

- `native/`：macOS原生源码、测试、资源和构建脚本。
- `docs/`：上述8份说明。
- `fixtures/`：合成JSON、图文RTFD、SQLite与加密报文样本。
- `tools/`：样本生成与资料校验工具。
- `SOURCE-MANIFEST.json`、`BUNDLE-MANIFEST.json`：文件校验清单。

样本不含用户真实任务或凭据。实际跨平台实现需要分别验证界面、文件/剪贴板、安全存储、RTFD双向编辑和双设备同步。
