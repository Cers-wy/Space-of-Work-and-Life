# 源码与测试索引

本文件提供当前功能、界面与特效对应的实现位置。源码链接固定到可核对的提交，方便按符号查阅。

## 1. 功能定位

| 功能 | 主源码 | 核对重点 |
|---|---|---|
| 主窗口、菜单、快捷键 | OrbitApp.swift | 1020x640最小尺寸、输入焦点、退出保护 |
| 状态与提交入口 | AppStore.swift | 草稿、项目复用、状态启停/迁移、撤销、导入、同步应用 |
| 骨架与筛选 | WorkspaceView.swift | 侧栏、概览、全库统计、分类快筛、条件浮层 |
| 颜色/基础控件 | Appearance.swift / Controls.swift / NavigationGlass.swift | token、玻璃、8圆角、等宽下拉、侧栏连续轮廓 |
| 任务卡与列表 | TaskViews.swift / BoardDragState.swift | 独立拖动状态、目标判定、空列、按需流光 |
| 任务表单与富文本 | TaskEditorView.swift / TaskDescriptionEditor.swift | 同次保存、未保存保护、图片/RTFD/附件 |
| 甘特与日历 | ScheduleViews.swift / TaskSchedule.swift / GanttProjectGroup.swift | 14天、闭区间、项目顺序、端点裁剪、月格溢出 |
| 日期控件 | SpaceDatePicker.swift | 周日开始、42格、快捷日期、清除策略 |
| 设置与状态管理 | SettingsView.swift / StatusEditorView.swift | 固定头尾及当前例外、迁移删除、数据整理 |
| 模型/查询/备份 | Task.swift / TaskQuery.swift / TaskRepository.swift / TaskAttachment.swift | 字段、UTF16、排序、JSON协议、总量 |
| 数据库 | SQLiteRepository.swift | schema、revision、WAL快照、只改偏好、恢复保护 |
| GitHub | GitHubDatabaseSync.swift / GitHubSyncController.swift / GitHubSyncView.swift | codec、指纹、SHA保护、状态机、Keychain、自动退避 |
| 手动SP同步 | DatabaseSync.swift / SyncSettingsView.swift | AES-GCM、2001epoch、码/receipt、合并策略 |

## 2. 关键行为定位

| 行为 | 对应源码 |
|---|---|
| 主界面新建默认工作；分类快筛只改变查询 | AppStore.create / WorkspaceView.categoryCounts |
| 日期选择器周日开头、任务周/月历周一开头 | SpaceDatePicker.days / ScheduleCalendar |
| 今天截止筛选比较真实due，允许已完成任务 | TaskQuery.apply |
| 默认结束为开始或今天加5自然日，闭区间含6个日期 | TaskSchedule.init / contains |
| 图文的普通文本镜像、RTFD和原附件分别保存 | TaskDescriptionEditor / OrbitTask |
| 附件列表移除与正文删图独立 | TaskAttachmentList / AttachmentPasteTextView |
| 甘特查看日期、日历选中日期及项目收展是临时状态 | GanttView / TaskCalendarView |
| 任务/设置固定头尾48，状态管理使用独立padding | SpaceSheetHeader / SettingsView / StatusEditorView |
| 只有done有完成语义，重开到todo | OrbitTask.changingStatus / AppStore.setStatus |
| 主题等偏好只改settings与revision，不重写任务 | TaskRepository.savePreferences |
| GitHub本地/远端双变冲突即停止，不自动合并 | GitHubSyncDecision.resolve |
| SP同ID按更新时间合并，相同时间不同内容拒绝 | DatabaseSync.merge |
| SP密文内日期按2001epoch，任务时间戳用ISO8601 | SnapshotContents / OrbitDate |
| 无悬停不持续刷新，前台悬停单卡播放流光 | TaskCard / CardFlowDecoration |
