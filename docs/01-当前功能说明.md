# Space 当前功能说明

软件：Space 个人工作台。适用界面：桌面应用。本文描述完整界面、功能、字段、操作与异常规则；具体视觉参数见 [界面与特效说明](02-界面与特效说明.md)。

# 1. 产品用途

Space 用于个人工作、个人事务和生活事项管理。用户在同一任务库中通过看板、列表、甘特图和日历查看、编辑和安排事项；数据优先保存在本机，断网时仍可完成本地操作。通过可选的 GitHub 私有仓库加密备份或手动快照，在设备间迁移和同步。

界面、业务规则与数据保护分别定义。使用者可以离线维护任务，也可以配置加密同步。开发者按文档实现同一组数据和交互，并分别验证功能与视觉效果。

# 2. 目标用户

| 用户角色 | 角色说明 |
|---|---|
| 工作台使用者 | 维护本人任务、状态、项目、排期与附件；没有多角色授权体系 |
| 多设备使用者 | 手动备份恢复，或配置私有仓库与恢复密钥，实现设备间数据交换 |
| 复刻开发者/测试者 | 在隔离工作区实现本资料包的行为与兼容性；不得用正式任务作自动化验收样本 |

# 3. 用户场景

| # | 触发场景 | 用户操作 | 期望结果 |
|---|---|---|---|
| 1 | 第一次打开应用 | 创建任务或导入备份 | 初始没有演示数据；保存后重启仍在 |
| 2 | 工作与生活事务混在一起 | 点击顶部分类、搜索、按项目/状态等筛选 | 四视图展示相同筛选集合；分类数字保持全库口径 |
| 3 | 任务进入下一阶段 | 跨列拖动、状态下拉或任务菜单改状态 | 完成时间与状态保持一致；可撤销最近一次操作 |
| 4 | 项目包含多个事项 | 在任务表单新建/复用项目，查看甘特图 | 项目按定义顺序分组，显示筛选后数量与总排期 |
| 5 | 任务需要截图和资料 | 编辑富文本、粘贴图片、上传文件 | 图文和附件完整保存；取消表单不写入 |
| 6 | 安排近期工作 | 选择查看日期，拖动甘特条 | 从查看日开始共 14 天，拖动按自然日保存 |
| 7 | 查看某日工作 | 日历日/周/月切换，点更多事项 | 按排期包含关系显示，不虚构小时；可从当日新增 |
| 8 | 更换电脑或误操作 | 导出、导入、恢复上一份、同步 | 校验后确认；失败保留原数据；恢复前备份 |

## 4.2 工作空间与概览（F01）

### 4.2.1 功能说明

单个主窗口提供左侧导航、顶部概览和主任务区域。侧栏与概览各自独立收起，不能让概览收起动作带动导航或清除筛选。

### 4.2.2 功能入口

启动应用 → 主工作台。侧栏只有“任务”业务入口，底部齿轮进入数据与设置。菜单仍可进入状态管理、视图、重载、外观和帮助。

### 4.2.3 页面及业务字段

| 字段/元素 | 控件/展示 | 默认值 | 规则 |
|---|---|---|---|
| 品牌 | S 图标，展开时 Space / 个人工作台 | 可见 | 没有“我”头像或本地工作空间身份卡 |
| 导航收起 | 图标按钮 | 首次收起 | 收起宽 64；顶端外凸箭头展开 |
| 顶部面包屑 | 我的空间 → 任务管理 | 概览展开 | 收起时显示当前范围与结果数 |
| 顶部分类 | 工作/个人/生活圆点及数字 | 全部未选 | 数字从全库计算，点击改变分类条件 |
| 概览统计 | 全部任务/进行中/已逾期/已完成 | 从全库计算 | 不是当前筛选结果；数字最少两位显示 |
| 四视图 | 看板/列表/甘特图/日历图标 | 看板 | 选中态、悬停说明、可访问名称 |
| 主题、状态、撤销、帮助、概览 | 顶部图标 | 撤销无记录时隐藏 | 概览收起仍可操作必要入口 |

### 4.2.4 操作逻辑

| 操作 | 系统处理 | 反馈与结果 |
|---|---|---|
| 点击“任务” | 将查询重置为默认 TaskQuery，包括默认排序 | 返回完整库；不改任务 |
| 收起概览 | 隐藏统计及展开筛选区，保留紧凑操作 | 筛选按钮打开浮层，不重新展开概览 |
| 切换视图 | 只改变 viewMode，沿用查询结果 | 四视图数据即时一致；视图选择持久化 |
| 切换主题 | 更新本地偏好并同步系统控件外观 | 无需重启，不改任务数据 |

### 4.2.5 业务及异常规则

只有“进行中”内置状态计入进行中统计，其他自定义未完成状态不计入该数字。已逾期是未完成且真实 due 早于北京时间今天；虚线默认结束日不算真实截止日。导航/概览/主题/视图偏好保存失败时应反馈，不能无声声称已保存。

## 4.3 搜索、筛选与排序（F02）

### 4.3.1 功能说明与入口

主界面条件栏；更多筛选按钮；收起概览后的“筛选与排序”；⌘F 或非输入状态 `/`。条件改变即时生效，无单独“查询”提交。

### 4.3.2 页面及业务字段

| 字段 | 控件 | 默认 | 取值与规则 |
|---|---|---|---|
| 关键词 | 文本框 | 空 | 去首尾空白后，在标题 + 普通说明 + 所属项目名中做本地化不区分大小写的子串匹配 |
| 状态 | 单选下拉 | 所有状态 | 含停用状态，带“已停用”标记 |
| 优先级 | 单选下拉 | 所有优先级 | 高/中/低 |
| 分类 | 单选下拉/顶部快筛 | 所有分类 | 工作/个人/生活；与顶部使用同一条件 |
| 截止日期 | 单选下拉 | 所有日期 | 今天截止/已逾期/未设置日期 |
| 项目 | 单选下拉 | 所有项目 | 已定义项目；当前没有单独“无项目”筛选选项 |
| 排序 | 单选下拉 | 截止日期优先 | 截止日期优先/优先级由高到低/最近创建优先 |
| 匹配数、清除 | 固定底栏 | 当前结果数 | 条件区滚动，标题与底栏保持可见 |

### 4.3.3 操作逻辑与业务规则

- 所有维度使用 AND，关键词在三个字段拼接后的内容中匹配。附件文件名与图片 OCR 不参与搜索。
- 再点当前顶部分类取消分类；切换到另一分类替换分类，不清除其他条件。
- 清除筛选重置关键词、状态、项目、分类、优先级、日期，保留查询 scope 和排序。仅更改排序不算有筛选。
- “显示所有任务”及侧栏“任务”直接重置 TaskQuery，也恢复默认排序；不要与“清除筛选”混为一个动作。
- “今天截止”日期条件比较 due 是否为今天，允许已完成任务。侧栏仅提供“任务”入口；逾期、完成和分类通过统计或筛选查看。
- 截止日期排序：有日期升序、无日期置末；日期相同按创建时间降序；仍相同按 ID 升序。
- 优先级排序：高→中→低，随后使用上述日期/创建/ID 兜底。
- 最近创建排序：先创建时间降序，再日期升序，再 ID 升序；不能把高优先级隐式插到前面。
- 查询在视图间保持，但当前未持久化搜索与筛选。退出重开恢复界面模式，不承诺恢复临时条件。

### 4.3.4 异常及边界

零结果时显示可调整条件的提示；列表空库提供新建/导入入口，看板仍可显示内置空列。关闭浮层不取消条件；选择下拉项后应立即更新匹配数。长项目名/状态名截断时可查看完整内容，不能撑破弹层。重置条件不应触发数据库任务保存。

## 4.4 任务新建、编辑与删除（F03）

### 4.4.1 功能说明与入口

顶部加号、看板列头/列底添加、日历当日添加、甘特图添加、快捷键新建；点击任务标题、排期条或任务菜单进入详情。所有入口共用同一编辑与校验流程。

### 4.4.2 页面及业务字段

| 字段 | 控件 | 必填 | 默认值 | 业务规则 |
|---|---|---|---|---|
| 标题 | 单行输入及计数 | 是 | 空 | 输入原文 ≤100 UTF-16 单位，保存去首尾空白；空白不能保存 |
| 所属分类 | 下拉 | 是 | 工作 | work/personal/life；顶部分类筛选不会自动预填同分类，见下文 |
| 状态 | 下拉 | 是 | 待办或新建所在列 | 只能新建到启用状态 |
| 优先级 | 下拉 | 是 | 中 | high/medium/low |
| 项目 | 下拉 + 新建项目 | 否 | 当前项目筛选或无项目 | 新建项目随任务同次提交；取消不创建 |
| 开始日期 | 日期选择器 | 否 | 空/nil | 与创建时间独立，不能晚于非空截止日期 |
| 截止日期 | 日期选择器 | 否 | 空或日历所选日 | 空字符串表示未设置；允许过去日期 |
| 任务说明 | 富文本及普通文本镜像 | 否 | 空 | 普通说明 ≤5,000 UTF-16 单位；富文本独立限制 |
| 附件 | 多文件选择、粘贴、列表 | 否 | 空 | 见 F07；取消不落库 |
| 创建/更新/完成时间 | 只读时间行 | 否 | 系统生成 | 详情显示，按北京时间格式化 |
| 创建/保存、取消、删除 | 固定底栏 | — | 新建不显示删除 | 保存失败保留表单和所有输入 |

### 4.4.3 操作逻辑

| 操作 | 系统处理 | 页面反馈 | 结果 |
|---|---|---|---|
| 新建 | 构造草稿，不写库；聚焦标题 | 表单显示默认值 | 保存前不增加任务计数 |
| 保存新任务 | 校验字段、定义和附件；最终提交时设置创建与更新时间 | 成功关闭；不符合筛选则提示“当前筛选条件下不可见” | 任务与新项目原子保存 |
| 保存已有任务 | 对比草稿 updatedAt 与当前任务，保留原 createdAt | 冲突/删除报错并保留输入 | 不把已被删除任务误当新任务插回 |
| 取消/X/Esc/退出 | 有改动先询问放弃 | 选择保留则继续编辑 | 放弃才丢弃草稿；不写入任务和附件 |
| 删除 | 显示任务名及可撤销说明，取消为安全选择 | 确认后关闭详情并刷新四视图 | 可单步撤销恢复完整任务 |

### 4.4.4 业务规则及边界

主界面新建任务的默认分类是“工作”。顶部分类快筛仅决定展示结果，不自动改变新建表单分类；用户可在表单选择“个人”或“生活”。从状态列新建预填该列状态，从指定项目筛选中新建预填对应项目。

已有任务停留在原停用状态可编辑其他字段，但不能移入其他停用状态。更新已完成任务的其他字段应保留原 completedAt；未完成改已完成设置当前时间；已完成改未完成清空 completedAt。数据载入失败、存在其他主要弹窗时不应创建第二份任务编辑表单。

## 4.5 完成、重新开启与撤销（F04）

### 4.5.1 功能入口

任务卡/列表/日历事项的完成圆圈；任务菜单移至状态；详情状态；顶部撤销或 ⌘Z。

### 4.5.2 状态规则

| 当前状态 | 操作 | 新状态 | 时间规则 |
|---|---|---|---|
| todo/doing/自定义 | 点击完成圆圈 | done | updatedAt 与 completedAt 都为该次时间 |
| done | 点击重新开启 | todo | completedAt=nil；不恢复到完成前的自定义状态 |
| 任意 | 移至与当前相同状态 | 不变 | 不更新、不重复保存 |
| done | 编辑内容但仍 done | done | 保留原完成时间，更新 updatedAt |
| 任意 | 移至自定义状态 | 自定义、未完成 | 清空完成时间 |

### 4.5.3 撤销逻辑与异常

每次成功任务/状态/项目定义变更记录上一次完整业务状态，最多一层；下次成功变更替换该层。撤销恢复任务、附件、富文本、项目、状态定义、顺序与启停；不等于把数据库文件直接覆盖回旧字节，也不恢复当前界面偏好。执行撤销仍须事务、备份、并发校验；成功后不提供“撤销撤销”或多步重做。重载/重启清空内存撤销记录。

文本编辑聚焦时 ⌘Z 交给文本系统，不误撤销整个任务库；有任务表单、设置或状态管理时业务撤销不执行。操作消息显示约 6 秒并可带撤销入口；没有常驻保存页脚。

## 4.6 自定义状态管理（F05）

### 4.6.1 入口、字段与操作

顶部状态图标或“工作台 → 任务状态管理”。显示状态名称、圆点、全库使用数、内置标记，及自定义状态的启用/停用/删除操作。输入框 + 新增按钮创建状态。

### 4.6.2 业务规则

- 内置状态固定 raw 值 `todo/doing/done`，不能删除、停用或改名；可随列顺序移动。
- 自定义名称去首尾空白、Unicode NFC 规范化，1～20 UTF-16 单位，无控制字符，不与现有名称大小写不敏感重复，不得使用内置中文名称。
- 自定义 raw 值为 `custom:` 加名称；只有 done 代表完成。最多 100 个状态（含内置）。
- 新状态插在 done 之前；自动增加看板列；空启用列必须持久保留。
- 停用不删除任务。有任务的停用状态仍显示列；空的停用状态不显示列。列是否显示按全库使用情况判定，不以筛选结果是否空判定。
- 停用后禁止新建或移动进入；原任务可保持该状态；筛选仍提供该状态。启用后恢复可选。
- 删除需选另一个启用状态，再确认迁移。任务 ID、标题、正文、附件、项目、排期等完整保留；迁移状态更新时间，目标若 done 则生成完成时间。
- 迁移任务、删状态、清除停用定义必须同次提交；失败全回滚。删除和排序可单步撤销。
- 列头三横线手柄拖到另一列位置，按目标索引移动整个状态；不对列内卡片提供任意手动排序。

### 4.6.3 异常及边界

重复/超长/空白名称应就地报错，旧状态保留。取消迁移删除保持任务和列；删除后失效的状态筛选自动清除。大量状态下拉限高滚动，不能超出窗口或漏掉已定义空列。

## 4.7 项目创建与复用（F06）

### 4.7.1 字段与操作

项目为可选关联，不是侧栏独立业务模块。任务表单支持“无项目”、已有项目或“新建项目”；新建输入 1～60 UTF-16 单位，去空白、NFC 规范化、禁控制字符。保存时已有同名（本地化不区分大小写）项目则复用其 ID，否则追加新项目定义。

### 4.7.2 业务规则

项目名显示在看板、列表、日历事项和甘特图项目父行，并参与搜索；筛选按 ID。项目顺序为定义顺序，保留到备份、恢复和 GitHub 逻辑快照。没有项目的任务归到甘特图末尾“未分配项目”。当前 UI 没有独立项目重命名、删除、排序或项目层级管理；不得凭空添加进基线。

项目随任务一次保存，取消或任务校验失败不得留下孤立的新项目。导入最多 10,000 个项目，ID 唯一、名称不重复、所有任务的项目引用必须存在。

## 4.8 图文说明与附件（F07）

### 4.8.1 字段及入口

详情富文本区、加粗/下划线按钮、⌘B/⌘U、正文粘贴、上传附件按钮、附件预览/另存/移除。富文本保存为 flat RTFD 字节，普通 description 保留可搜索文本镜像。

### 4.8.2 操作逻辑与业务规则

- 正文输入和格式编辑只改草稿；保存后重开保留文字、顺序、加粗、下划线和图像。取消整个任务编辑不提交。
- 粘贴优先处理文件 URL，其次 PNG，其次可转 PNG 的 TIFF，普通文本回退到系统粘贴。
- 粘贴图片时先校验整批文件；成功后同时加到附件列表，在当前光标/选区位置插入内嵌图及换行。图像预览按比例缩至最大 480×240，不放大；原始字节仍保留。
- “上传附件”选择图片时只添加到附件列表，不自动在正文光标插图。不要把两个入口混淆。
- 非图片文件保存为附件；不虚构正文中的文件内容。可预览、另存和移除；图片用缩略图，其余用文件图标、名字、大小。
- 单个附件 ≤10 MiB；每任务 ≤20 个、合计 ≤20 MiB；富文本字节 ≤24 MiB；JSON 总体 ≤64 MiB。限制使用 1024 制字节，界面文案可以沿用 MB。
- 附件 ID 唯一，名称 1～255 UTF-16 单位，禁路径分隔、控制字符、`.`/`..`；类型标识非空，具体字节限制见数据字典。
- 字节进入任务 payload；保存后原来源文件被移动/删除仍可查看与另存。预览以随机临时目录存放，不能把导入的附件 ID 当作目录路径。
- 富文本内图片与附件列表中的原图独立保存。从附件列表移除原图不会删除正文中的图；删除正文图片也不自动移除附件。

### 4.8.3 异常及边界

坏图、任一超限文件、文件夹、权限错误：整批失败并显示可读原因，不先插半批图或修改正文。预览不可用时仍能另存；移植平台的替代能力在交接文档中明确。不能用“不支持 RTFD”作为静默丢弃富文本的理由。

## 4.9 看板（F08）

### 4.9.1 页面字段

状态列头：拖动手柄、状态色点、名称、停用标记、筛选后数量、添加。卡片：分类、操作菜单、项目（可选）、标题最多 3 行、普通说明最多 2 行、优先级、真实截止标记、完成按钮。

### 4.9.2 操作与业务规则

列最小 280，空间足够均分，列间 12；超宽只在看板内横滚，每列任务独立纵滚、列头固定、整列完整圆角裁切。卡片顺序来自共享排序；手动拖动只用于改状态。

拖动超过约 8 逻辑点开始，原卡降低透明度、显示独立拖动预览、目标列描边；在看板视口内命中有效列才提交。落在外部、原列、无效或停用目标时不改变任务。失焦或离开看板重置拖动状态。

空列仍有“添加任务”和空态说明，停用列添加置灰。卡片内部光与四周光边共存；只有悬停单卡且前台、无拖动、未开启减少动态效果时持续动画。拖指针不能让整个工作台每帧重新计算任务和附件。

## 4.10 列表（F09）

### 4.10.1 页面字段与操作

固定表头：任务名称、分类、状态、优先级、截止日期、操作。行包含完成圆圈、标题（最多 2 行）、项目（可选）、说明（最多 1 行）；状态为统一下拉。点击标题开详情，圆圈完成/重开，下拉改状态，省略号或右键菜单编辑/移状态/删除。

### 4.10.2 规则与异常

字段对齐、行内容纵向滚动，标题是弹性列。日期徽标只取真实 due，未设置为“未设置”，不显示甘特默认截止。今天截止着蓝色；未完成的过去 due 显示“已逾期 · 月日”。当前没有批量勾选、批量删除、分页、独立列表排序规则或任意列配置。

## 4.11 甘特图（F10）

### 4.11.1 页面及业务字段

工具栏：甘特图名称、日期范围、全部展开/收起图标、查看日期选择器。左区宽 400，显示项目/任务名、状态、开始/截止；右区 14 个自然日。初始查看日为今天。标题行固定；任务行高 64、项目行高 48；日列最小 48，不足时整体横滚。

### 4.11.2 排期计算

| 任务条件 | 显示开始 | 显示结束 | 是否默认 |
|---|---|---|---|
| 有真实 due | 显式 startDate，否则创建日；不晚于结束 | due | 否 |
| 未完成、无 due、无 startDate | 今天 | 今天 +5 自然日 | 是 |
| 未完成、无 due、有 startDate | startDate | startDate +5 自然日 | 是 |
| 已完成、无 due | startDate 或创建日，收敛到不晚于结束 | completedAt 的北京时间日期 | 否 |

“加 5 天”是两个日期的差值，闭区间实际覆盖 6 个日期；“14 天视窗”为 anchor 到 anchor+13。只查看不写回字段，默认结束不参与逾期判断。

### 4.11.3 操作逻辑与业务规则

- 按定义顺序列出有筛选结果的项目；空项目不显示。未分配项目最后显示。项目数量和总排期仅来自当前筛选后的子任务。
- 点击项目父行收展；全部收起/展开仅影响当前视图临时状态。项目总排期是全部可见子任务最早开始到最晚结束；父条不能拖动。
- 任务条颜色按状态；默认条虚线，已完成显示完成标记；时间窗外部分裁剪，完全不相交任务仍在左侧列表但无条。
- 拖中部整条平移，保持闭区间时长；拖左端只调开始、右端只调结束；四舍五入吸附自然日，最短同一天。
- 只有真实端点在视窗内才显示该端手柄；拖动计算使用完整排期，不把裁剪后的片段当原始排期。
- 拖动中只本行预览；松开且日期确实变化才提交一次。保存显式 startDate 和 due，更新 updatedAt，保留 createdAt、状态和完成时间；单步撤销可恢复原本无日期。
- 拖动前后任务内容发生变化则拒绝覆盖并提示重新拖动。零移动、缩到同一天后继续反向越界，不应产生多余写入。
- 点击任务名/条中部仍进入详情。视窗日期及项目收展未持久化；切离销毁视图后重新进入会回到当前日和初始展开状态。不可承诺永远保留上一次查看日期。

## 4.12 日历（F11）

### 4.12.1 页面与字段

工具栏有查看日期、周期标题和“日/周/月”分段按钮；初始月模式，模式可持久化。日历没有小时字段，不显示时段网格。

### 4.12.2 操作与规则

- 每任务沿用甘特图同一 TaskSchedule；当日位于开始～结束闭区间就显示，跨天任务可连续出现在多天；不是仅截止当天显示。
- 月历周一开头，行数按当月覆盖日期补齐为整周（4/5/6 周），包含相邻月日期。点日期选中，右侧展示该日完整清单。
- 月格预览数根据高度计算、限制 1～3；超出显示“还有 N 项”。日期、预览与更多按钮均在本格内，裁切不能遮住下一行。点击更多只选中当日，不自动改视图。
- 点月格内任务按钮选中当日并开详情。今日日期圆形主色强调，选中格另有边框和底色。
- 周视图为周一至周日，七列，每列最小 148，有独立任务纵滚及添加事项；不足横滚。点列头只改选中日。
- 日视图显示选中日完整清单。事项行提供完成/重开、标题详情、分类、状态、真实/默认截止说明、项目；宽日视图提供操作菜单。
- 从任意日的“添加事项”进入任务表单，due 预填该日，保存前不增加任务。
- 选择查看日期同时更新 selected 与 anchor；切换日/周/月把周期 anchor 对齐选中日。选择器不允许清空查看日期。
- 选中日期与 anchor 是视图局部状态，未写入设置；查看日期通过日期选择器切换。

### 4.12.3 异常边界

筛选零结果仍保留日期和空态；当天无事项提供添加/选择日期提示；长标题截断但可打开详情。闰年、跨年、月底换月与北京时间午夜均以公历自然日计算，不能按秒数累加造成日期偏移。

## 4.13 日期选择器（F12）

### 4.13.1 页面及操作

按钮为日历图标、日期或“未设置”、下箭头；展开 304 宽浮层。月头前/后月、年/月文本；固定 42 格、以周日开头；今天、明天、可选清除。选日期立即关闭；Esc 关闭但不改日期。

### 4.13.2 规则

有值从该日期所在月展开，无值从今天所在月展开；可选相邻月格并准确返回其完整日期。表单允许清除 startDate 和 due；查看日期选择器禁止清除。所有日期字段采用 `YYYY-MM-DD`，只读显示不能误用本机其他时区。

日期选择器以周日为第一列；任务周历和月历以周一为第一列。两套网格分别按各自规则排列。

## 4.14 本地数据（F13）

### 4.14.1 功能与入口

启动载入本地 SQLite；首次没有数据库时建立空库，存在 tasks.json 则校验并导入；数据与设置显示实际路径并提供文件管理器定位。

### 4.14.2 保存与错误保护

每次成功业务提交先校验所有字段、定义和引用，取得写入锁，核对预期 revision，生成上一份一致快照，再在事务中替换业务表并写新 revision。只有成功后才发布新内存状态；任一步失败保留已接受数据和草稿，并反馈具体原因。

界面偏好只更新 settings 和 revision，不重写任务 payload，不替换最后一次任务恢复快照。重载失败不当作空库，不自动清空或覆盖损坏原件；只允许明确导入有效备份进行恢复。

macOS 数据目录是 `~/Library/Application Support/com.cers.orbit/`，目标平台使用该系统用户级应用数据目录，必须在设置中可见。验证副本使用独立应用身份及目录；不得复用正式数据库或凭据。

## 4.15 导入、导出与恢复（F14）

### 4.15.1 页面字段与操作

数据与设置 → 备份与恢复：导出 SQLite、导出 JSON、导入备份、恢复上次备份。默认导出文件名 `Space-任务备份-YYYY-MM-DD`。

| 操作 | 处理顺序 | 成功结果 | 错误结果 |
|---|---|---|---|
| 导出 SQLite | 检查目标、revision → Backup API 一致快照 → 原子写 | 独立可打开文件含已提交 WAL 内容 | 不覆盖活动库和上一份恢复文件 |
| 导出 JSON | 按内容选择协议版本 → 编码 → 原子写 | 完整任务及可携带定义/设置 | 超限则报错，不声称成功 |
| 导入 | 检测文件头 → 完整校验 → 显示来/本地数量 → 确认 | 先本地备份，再替换任务/项目/状态；清除查询，载入偏好 | 任何失败不改当前任务 |
| 恢复上一份 | 读取 previous → 校验 → 明确确认 | 恢复完整业务数据及可导入设置 | 文件不存在禁用，损坏报错 |

### 4.15.2 业务规则

导入是整库替换，不是普通文件合并；读取支持 SQLite 版本 1～3 与 JSON V1～V6。JSON/SQLite 文件导入上限均 64 MiB；最多 10,000 任务。普通本地备份可能包含界面偏好、同步地址用户名，但密码/Token/恢复密钥不在其中。

导入时保留本机 `sync.*` 设置，其他设置覆盖键来自备份；GitHub 独立连接文件不随 SQLite 导入替换。当前 import 操作保留本机 workspaceID，不直接把外部库 identity 克隆成自己的身份。旧 JSON 原件保持不变；恢复 previous 会在提交前保存恢复操作之前的当前库。

## 4.16 GitHub 私有仓库同步（F15）

### 4.16.1 入口与字段

数据与设置 → GitHub 私有仓库同步。账号、私有仓库、分支、路径；隐藏输入的 Token 和恢复密钥；自动开关；保存配置、创建访问令牌、首次生成密钥、复制已存密钥；检查并同步、下载预览、用本机覆盖云端。

### 4.16.2 用户操作逻辑

首次配置前不能同步。默认目标 `18390208101/space-sync-data`、`main`、`backups/latest.space`，这些只是可编辑默认值；源码备份仓库 `Space-macOS-native` 与任务同步仓库用途不同。

配置未保存、缺凭据、未载入数据、另一同步正在处理、正在编辑任务时禁止相关动作。保存后清空密码型输入显示，但留空可沿用本机已存凭据。首次上传要确认；云端存在且本地无基线时先下载校验，内容不同则预览确认恢复。

云端预览显示任务/项目/状态数量；取消不修改本地。恢复需再次确认，保存本地 previous 后替换业务数据；保留本机外观和连接。自动同步仅在手动建立基线后按 30 秒防抖、5 分钟或重新激活触发；退出不运行。

### 4.16.3 冲突与异常

本地与云端都变化、或已有基线的云端文件被删除，停止自动覆盖。用户可下载预览后恢复，或明确覆盖云端；没有自动合并。密钥错误/篡改/超限、无权限、非私有仓库、缺分支、旧 SHA、断网均保留本地，错误不能回显凭据。完整决策表及兼容报文见 [04](04-同步与加密实现要求.md)。

## 4.17 其他位置手动快照同步（F16）

### 4.17.1 入口、字段与操作

数据与设置 → 其他位置的手动快照同步。位置（HTTPS/WebDAV 目录或已挂载文件夹）、可选用户名/密码、保存配置、上传数据库备份、复制验证码、输入另一设备 SP 验证码、下载并校验。

### 4.17.2 业务与状态规则

上传取得完整 SQLite 快照，生成随机 128 位材料的 SP 码并加密上传。两端使用相同位置，码有效 7 天。下载后先校验并显示数量，再选择取消、备份并合并或备份并替换；两种应用方式均需确认。

合并是任务集合并集，同 ID 按 updatedAt 较新版本保留；时间相同但内容不同拒绝，不随机选择。项目按不区分大小写的名称复用并改写远端任务引用；同 ID 不同项目发生冲突则拒绝。合并不传播删除；这是与 GitHub 整库同步的重要差异。

下载期间 revision 变化则拒绝继续；预览后本地再次变化也不能应用旧预览。已应用 receipt 历史最多保留 64 条，重复码不重复应用。详情见 [04](04-同步与加密实现要求.md)。

## 4.18 外观、辅助功能与快捷键（F17）

### 4.18.1 要求

双主题为蓝色奶白与黑灰亮紫毛玻璃，使用原生定义的颜色/层次、8 逻辑点矩形圆角及苹方字体。非苹果平台不能私自分发苹方，应提供合规替代并记录度量差异。完整参数见 [02](02-界面与特效说明.md)。

图标按钮必须有悬停说明、可访问名称、选中/禁用/焦点反馈；颜色不能独自承担状态识别。系统减少动态效果时关闭布局位移动画与持续流光，仅保留短淡入；降低透明度时切换实底。中文菜单与系统文件选择/保存面板可用。

| 动作 | macOS 基线 | 目标平台要求 |

| 撤销 | ⌘Z | 输入控件内为文本撤销，其余为业务撤销 |

## 4.19 数据整理（F18）

“载入演示任务”明确确认后以 10 项样本替换任务；当前代码沿用现有项目/状态定义。不得在首次启动、导入失败或缺凭据时自动填演示。清空所有任务需确认并可撤销；清空只移除任务，项目、状态定义及偏好保留。无任务时清空按钮禁用。

# 5. 全局异常和一致性要求

| 场景 | 必须行为 |
|---|---|
| 磁盘满、只读、锁失败、事务失败 | 不发布未保存的成功状态，保留草稿和原库，显示可行动提示 |
| 数据损坏、未来协议版本 | 显式读取失败，不能默认为空；提供重载/导入恢复入口 |
| 外部进程已写入 | revision 不匹配就停止，不以本机旧快照覆盖 |
| 编辑的任务被其他操作修改/删除 | 保留草稿并提示冲突或删除，不误新建 |
| 操作重复点击 | busy/编辑状态限制重复提交；成功一次只新增一条任务 |
| 同步失败、离线 | 本地功能继续；同步消息区说明原因、退避与恢复方式 |
| 数据过大、引用错误 | 整份拒绝，不部分导入后才报错 |
| 弹窗高度不足 | 正文滚动，固定头/底栏可见，不能裁掉保存/取消按钮 |
| 恢复/清空/删除取消 | 原任务、附件、定义、偏好均保持原状态 |

# 6. 验收与跨平台实现

验收必须使用 [05-验收用例](05-验收用例.md)。每个平台提交实际构建、可安装/运行产物、隔离测试记录、关键截图和已知差异；自动化通过与视觉验收分别记录。跨平台交互建议与任务拆分见 [06](06-跨平台开发说明.md)。

跨平台实现需要明确目标系统、CPU 架构、字体、RTFD 双向读写和系统预览方式。功能与测试位置见 [源码与测试索引](07-源码与测试索引.md)；各平台按相同验收用例记录结果。
